MACBETH REVISION — THE PURPLE ARCHIVE

HOW TO USE
1. Extract the ZIP file.
2. Open the folder and double-click index.html to preview the website in your browser.
3. To publish it online, upload the extracted files (especially index.html) to a static website host such as Netlify, GitHub Pages, or Cloudflare Pages.

FEATURES
- Animated purple galaxy background made with CSS (no external images needed).
- Theme filters: Ambition, Independence, Divine Right of Kings, Great Chain of Being.
- Quote library with speaker, act/scene, meaning, analysis and context.
- Search and character filters.
- Randomised multiple-choice quiz with instant feedback and a score.
- Responsive layout for phones and computers.

NOTES
The site is a revision aid, not a replacement for your class text or teacher's notes. Shakespeare's wording and punctuation can vary slightly by edition.
Everything runs locally in your browser; no account, API key or server is required.
